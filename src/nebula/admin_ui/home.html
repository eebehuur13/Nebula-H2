Nebula

Rocket Learning's memory for Claude. Claude can search the Drive files you can open and answer number questions from spreadsheets.

1

Add Nebula to Claude

  1. On claude.ai, go to Customize → Connectors → Add custom connector.
  2. Name it Nebula, and paste this address as the URL.
    {{MCP_URL}}
  3. Click Connect and sign in with your {{ACCOUNT}}. Google's screen shows Nebula's server address ({{HOST}}), so that's expected.
  4. Start a new chat and check that Nebula is switched on in the chat's tools menu. When Claude asks to use a Nebula tool, choose Always allow. Otherwise Claude asks again at every step.
